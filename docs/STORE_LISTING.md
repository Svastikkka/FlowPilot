# Chrome Web Store submission notes

## Listing

**Name:** FlowPilot — Local Browser Automation

**Short description (≤132 chars):**
Build, save and run browser workflows locally. No accounts, no cloud, no tracking.

**Category:** Developer Tools (alternative: Productivity)

**Detailed description:**

> FlowPilot automates repetitive browser tasks while keeping your data on your
> device.
>
> • Visual workflow editor: add, reorder (drag and drop), duplicate, disable
>   and configure steps, with validation feedback.
> • 15 built-in actions: open pages, click, type, select, check boxes, wait for
>   elements or text, extract text, capture URL/title, scroll, screenshots,
>   confirmations, copy results, and more.
> • Variables, inputs you enter at run start, secret values, and built-in dates.
> • Logic without code: If / Else, Repeat, While, For each element, For each
>   CSV row, and Set variable with text and number operations.
> • Data in, data out: import a CSV and run once per row, and collect results
>   into a table you can download as CSV or JSON.
> • Reliable runs: automatic waiting, timeouts, retries and per-step error
>   handling (stop, skip or ask you), plus pause, resume and stop.
> • Test a single step against the real page while you build.
> • Live execution monitor, run history, and JSON/CSV export of results.
> • Templates for form entry, page extraction and visiting lists of URLs.
> • Import and export workflows as validated JSON. Workflows can never run
>   custom scripts.
>
> Privacy first: no account, no servers, no analytics. Workflows and history
> are stored only in your browser. FlowPilot can access only the sites you
> allow, and asks before steps that look like submissions, purchases or
> deletions.

## Single purpose

FlowPilot lets the user create and run their own step-by-step browser
automation workflows on websites they choose.

## Permission justifications

| Permission | Justification |
|---|---|
| `storage` | Stores the user's preferences locally. |
| `unlimitedStorage` | Stores the user's workflows, run history and screenshots locally; screenshots can exceed the default quota. |
| `scripting` | Injects the extension's own bundled script into the tab a workflow is running in, to perform the user's configured actions (click, type, read text). No remote code. |
| `activeTab` | Lets the user run a workflow on the page they are viewing, from the toolbar button, without granting permanent host access. |
| Optional host permissions (`<all_urls>`) | Requested at run time, per site, only for sites the user's workflow opens. "All sites" is requested only if the user opts in (needed for screenshots and dynamic URLs). |

**Remote code:** None. All JavaScript is bundled in the package. Workflows are
data that is validated against a fixed schema; there is no eval or dynamic
code execution.
